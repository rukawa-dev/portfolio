# 1. [섹션 1] 상세 정보 입력

---

### 1-1. 서비스 설명 (필수 *)
> 크몽 에디터 상자에 아래 전체 내용을 그대로 복사해서 붙여넣으세요.

```text
[14년 차 UI/UX 퍼블리싱 수석연구원] 1일 완성! 막막한 웹 코딩, 1px의 오차 없이 완벽하게 끝내드립니다.

안녕하세요!
대기업(LG, 삼성), 대학교 및 공공기관 웹접근성(WA) 총괄 PL, 이커머스 플랫폼 개발 수석연구원 출신 14년 차 전문 웹 퍼블리셔 '근면성실아저씨'입니다.

"디자인 시안(Figma/PSD)은 다 나왔는데, 코딩할 전문 퍼블리셔가 없으신가요?"
"스마트폰이나 태블릿에서 사이트가 와장창 깨져 보여 급하게 수정해야 하나요?"
"오픈 일정이 당장 내일이라 밤샘 없이 1일 만에 끝내줄 시니어 전문가가 필요하신가요?"

저는 디자인 창작이나 백엔드 개발을 흉내 내지 않습니다.
오직 '웹 퍼블리싱(HTML5 / CSS3 / JavaScript / 반응형 / 웹접근성)' 한 우물만 14년간 파온 전문성으로, 디자이너의 의도를 100% 살린 정밀한 코드와 개발자가 쓰기 편한 명품 마크업을 약속드립니다.


■ 왜 퍼블리싱은 '근면성실아저씨'에게 맡겨야 할까요?

1. 압도적인 속도, '1일 완성' 원칙
- 긴급 수정 및 단일 페이지는 상담 후 당일 납품을 원칙으로 합니다. 약속한 마감 기한은 목숨처럼 엄수합니다.

2. 디자인과 100% 일치하는 '픽셀 퍼펙트 (Pixel-Perfect)'
- Figma, PSD, XD 시안의 폰트, 자간, 여백, 비례를 1px의 오차 없이 웹 브라우저 화면에 그대로 재현합니다.

3. 모든 디바이스에 완벽 반응하는 '올디바이스 최적화'
- PC, 모바일, 태블릿, 폴더블폰까지 어떤 화면에서도 깨짐 없이 부드럽게 동작하는 반응형 웹을 구축합니다.

4. 누가 봐도 감탄하는 '명품 클린 코드 & 주석'
- 백엔드 개발자나 초보자도 쉽게 이해하고 수정할 수 있도록 시맨틱 태그 구조화와 친절한 한글 주석(Comment)을 달아드립니다.

5. 웹표준 & 웹접근성(WA) 100% 준수
- 공공기관·대학교 웹접근성 인증 총괄 PL 경험으로 검색엔진(SEO)에 최적화된 탄탄한 코드를 보장합니다.


■ 전문 작업 범위 안내

- Figma(피그마), Photoshop(PSD), XD, 이미지 시안의 정밀 웹 퍼블리싱 변환
- 모바일/태블릿 반응형 웹 퍼블리싱 (메인페이지, 서브페이지, 랜딩페이지)
- 기존 웹사이트의 깨진 레이아웃 수정, 모바일 최적화, 텍스트/배너 교체
- Swiper 슬라이더, 모달 팝업, 탭 메뉴, 아코디언 FAQ 등 JavaScript/jQuery 인터랙션 구현
- 웹 표준 시맨틱 마크업 및 접근성(WA) 품질 교정
- React.js 기반 컴포넌트 마크업 및 프론트엔드 퍼블리싱 협업

※ 디자인(시안 제작) 및 백엔드(DB/서버 개발)는 진행하지 않으며, 오직 완성도 높은 웹 퍼블리싱 코딩에만 집중합니다.


■ 빠르고 정확한 4단계 작업 프로세스

1. 상담 및 견적 안내 : 디자인 파일(Figma 링크 등) 및 요청사항 확인 후 합리적인 견적 안내
2. 결제 및 즉시 코딩 착수 : 웹 표준 시맨틱 마크업 및 반응형 정밀 코딩 진행
3. 1차 검수 및 피드백 수정 : 전달드린 작업물 확인 후 요청사항에 맞춰 디테일 보완 (무제한 무상 수정)
4. 최종 납품 및 완료 : HTML/CSS/JS/이미지 에셋 압축파일(zip) 전달 및 요청 시 호스팅/FTP 서버 세팅 무료 지원


고민은 결과물 완성만 늦출 뿐입니다!
디자인 파일이 완벽하지 않아도 괜찮습니다. 참고하고 싶으신 샘플 사이트 링크(URL)만 주셔도 친절하게 가이드해 드립니다.

지금 바로 우측 [문의하기]를 눌러 메시지를 보내주세요!
10분 이내에 친절하고 명쾌하게 상담해 드리겠습니다. 감사합니다!
```

### 1-2. 주요 정보 선택 (필수 *)
화면에 나오는 각 드롭다운 목록에서 아래 항목들을 선택/체크하세요.

### 1-3. 메인 이미지 (썸네일)

### 1-4. 서비스 제공 절차 (필수 *)
> 입력 상자에 아래 4단계를 복사해서 붙여넣으세요.

```text
STEP 01. 무료 상담 & 맞춤 견적 안내
- 디자인 파일(Figma/PSD 등)과 요구사항을 확인하고 합리적인 견적 및 일정을 제안해 드립니다.

STEP 02. 결제 및 즉시 코딩 착수
- 결제 확인 즉시 웹 표준 시맨틱 마크업과 반응형 코딩을 빠르게 진행합니다.

STEP 03. 1차 검수 및 피드백 반영
- 완성된 작업물을 확인하신 후, 클라이언트의 피드백에 맞춰 디테일을 무제한 수정해 드립니다.

STEP 04. 최종 납품 및 프로젝트 완료
- 최종 검수가 끝난 HTML/CSS/JS 소스 압축파일(zip)을 전달해 드립니다. (요청 시 호스팅/FTP 서버 세팅 지원)
```

### 1-5. 의뢰인 준비사항 (필수 *)

```text

- 디자인 시안이 없으신 경우 '원하시는 분위기의 샘플 사이트 URL'을 보내주시면 됩니다.

2. 작업 환경 및 사이트 정보
- 신규 제작 : HTML 소스 파일(zip) 납품 또는 서버(FTP) 업로드 여부
- 기존 사이트 수정 : 운영 중인 사이트 주소(URL) 및 수정 필요 부분 캡처
- 작업 환경 : 일반 정적 HTML/CSS/JS / React 컴포넌트 등

3. 필요한 기능 & 인터랙션
- 이미지 슬라이더(Swiper), 탭 메뉴, 모달 팝업, 스크롤 애니메이션 등 필요하신 기능을 말씀해 주세요.

4. 희망 마감일
- 결과물을 받으셔야 하는 최종 날짜를 말씀해 주시면 우선 일정을 조율해 드립니다.
```

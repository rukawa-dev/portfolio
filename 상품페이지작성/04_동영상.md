# 🎬 Google NotebookLM 활용 크몽 홍보 영상 제작 가이드

Google NotebookLM의 **Audio Overview(오디오 브리핑/팟캐스트 생성)** 기능을 활용해 1분 만에 고품질 소개 음성을 뽑고, 이를 상세 이미지와 결합하여 크몽용 MP4 영상을 제작하는 방법입니다.

---

## 1. NotebookLM 업로드용 소스 텍스트 (복사하여 소스 추가)

> **사용법**: [NotebookLM](https://notebooklm.google.com/) 접속 ➔ [새 노트북] ➔ [소스 추가 (텍스트 복사/붙여넣기)]에 아래 내용을 그대로 넣으세요.

```text
[전문가 프로필]
- 전문가명: 근면성실아저씨 (14년 차 시니어 웹 퍼블리셔)
- 핵심 분야: 100% 순수 웹 퍼블리싱 및 UI/UX 마크업 전담 (디자인 및 백엔드 제외)
- 경력: 대기업(LG, 삼성), 대학교 및 공공기관 웹접근성(WA) 총괄 PL, 이커머스 플랫폼 개발 수석연구원 출신

[핵심 서비스 및 강점]
1. 1:1 픽셀 퍼펙트 구현: Figma, Adobe XD, Photoshop 시안의 여백, 폰트 자간, 레이아웃을 1px의 오차 없이 브라우저에 100% 완벽 구현
2. 완벽한 반응형 웹 (Responsive): PC, 태블릿, 모바일 전 기기 해상도 대응 유연한 미디어쿼리 구축
3. 크로스 브라우징 완벽 호환: Chrome, Safari, Edge, 모바일 브라우저 100% 동일 렌더링
4. 웹 표준 & 웹 접근성(WA) 준수: W3C 표준 시맨틱 태그, 스크린 리더 대응, 직관적인 클래스 구조로 개발자 인계 용이
5. 긴급 작업 1일 당일 완성: 오픈 일정이 촉박한 프로젝트에 맞춘 신속·정확한 납품

[기술 스택]
- HTML5, CSS3, SCSS (Flexbox, Grid)
- JavaScript (ES6+), jQuery (인터랙션/플러그인)
- React (정적 JSX/TSX 컴포넌트 마크업)
- Figma, Adobe XD, Photoshop, Zeplin, Bootstrap, Git

[서비스 패키지]
- STANDARD (20,000원~): 간단한 섹션 수정, 깨진 레이아웃/CSS 긴급 보수 (1일)
- DELUXE (40,000원~): 반응형 1페이지 마크업, 슬라이드/탭/모달 인터랙션 (1~2일)
- PREMIUM (150,000원~): 고난도 반응형 롱스크롤 랜딩페이지 풀패키지 (3~5일)
```

## 2. NotebookLM 프롬프트 (오디오 오버뷰 & 스크립트 생성용)

### 🎙️ [프롬프트 1] 60초 크몽 서비스 홍보 영상 스크립트 작성
```text
이 소스 문서를 바탕으로 크몽에서 웹 퍼블리싱 서비스를 찾는 클라이언트들의 마음을 사로잡을 수 있는 60초 분량의 매력적인 영상 나레이션 스크립트를 작성해줘. 
14년 차 시니어 전문가의 신뢰감, 1:1 픽셀 퍼펙트, 빠른 작업 속도, 합리적인 가격을 강조해줘.
```

### 🎧 [프롬프트 2] NotebookLM Audio Overview 생성 지침 (Deep Dive)
> NotebookLM 우측 상단 **[Audio Overview] -> [Customize (맞춤설정)]** 클릭 후 아래 지침 입력:

```text
Focus on explaining the pure web publishing services of a 14-year senior developer ('근면성실아저씨'). Emphasize 1:1 pixel-perfect markup from Figma, flawless responsive design across mobile/tablet/PC, fast 1-day delivery, and high satisfaction for clients needing HTML/CSS/JavaScript markup without design/backend overhead.
```

## 3. 5분 완성 MP4 영상 제작 워크플로우

1. **오디오 다운로드**: NotebookLM에서 생성된 오디오를 `.mp3` 또는 `.wav`로 다운로드합니다.
2. **비디오 편집 도구 선택**: [Vrew](https://vrew.voyagerx.com/ko/) (자동 자막 생성 추천), [Canva](https://www.canva.com/), 또는 [CapCut] 실행.
3. **화면 구성**:
   - 배경 화면으로 우리가 제작한 상세 이미지([kmong_detail_01_hero_badges.jpg](file:///C:/projects/portfolio/상품페이지작성/kmong_detail_01_hero_badges.jpg), [kmong_detail_02_guarantee_process.jpg](file:///C:/projects/portfolio/상품페이지작성/kmong_detail_02_guarantee_process.jpg)) 및 썸네일 이미지 배치
   - 다운로드한 NotebookLM 오디오 삽입 및 자동 자막 생성
4. **MP4 내보내기**: 1080p MP4로 내보내기 후 크몽 **[동영상]** 란에 업로드(500MB 이하).

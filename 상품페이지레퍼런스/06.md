# [PART 5] 자주 묻는 질문 (FAQ) & A/S 환불 규정

**Q1. 작업 전에 어떤 자료를 준비해야 하나요?**
- **A**: 디자인 시안(PSD, Figma, XD 등)과 참고 자료를 보내주시면 확인 후 견적과 일정을 안내드립니다. 스토리보드가 있다면 함께 첨부해 주세요.

**Q2. 작업 기간은 얼마나 걸리나요?**
- **A**: 기준 범위 내 1페이지는 결제 후 익일에 작업물을 전달드립니다. 여러 페이지 또는 반응형 작업은 상담 시 일정을 안내드립니다.

**Q3. 반응형 웹 작업도 가능한가요?**
- **A**: 네, 가능합니다. Desktop(1200px), Mobile(768px) 기준으로 작업하며, 다른 해상도 기준이 필요하시면 상담 시 협의 가능합니다.

**Q4. 크로스 브라우징을 지원하나요?**
- **A**: 네, 모든 패키지에 크로스 브라우징이 포함되어 있어 크롬, 엣지, 사파리 등 주요 브라우저에서 동일하게 보이도록 작업합니다.

**Q5. 작업물은 어떻게 전달되나요?**
- **A**: HTML/CSS/JS 소스 파일로 전달드리며, 요청하시면 운영 중인 서버에 직접 업로드까지 지원해 드립니다.

   - 단순 퍼블리싱 단가를 넘어, '14년차 수석연구원의 시니어 안정성'과 '웹접근성 표준 보증'을 내세워 타 저가형 프리랜서와의 가격 경쟁을 피하고 신뢰 기반의 수주를 달성.
2. **업셀링 구조**:
   - 2~5만 원대 STANDARD로 유입된 고객에게 반응형(DELUXE) 및 메인 풀패키지(PREMIUM)의 가치를 제안하여 평균 객단가를 15~30만 원 이상으로 견인.
3. **재의뢰(단골) 루프 형성**:
   - 꼼꼼한 코드 주석과 친절한 소통, 7일 무상 A/S를 제공함으로써 에이전시, 스타트업, 마케터들의 고정 외주 파트너로 자리매김.
